בהתבסס על כל המידע שנאסף, אנא ספק/י ניתוח מקיף הכולל:

1. **ניתוח פדגוגי מלא בטקסט חופשי** - ניתוח מקיף, מפורט, ומעמיק של התלמיד/ה הכולל את כל הממצאים, תובנות, והמלצות בסגנון פדגוגי מקצועי
2. **נתונים מובנים בפורמט JSON** - אותו ניתוח בפורמט מובנה לתצוגה ויזואלית

**חלק א: ניתוח פדגוגי מלא (טקסט חופשי)**

אנא כתוב/י ניתוח פדגוגי מקיף ומפורט (3-5 פסקאות לפחות) הכולל:
- פרופיל כללי של התלמיד/ה
- ניתוח מעמיק של החוזקות והאתגרים
- תובנות פדגוגיות והמלצות מעשיות
- יעדים וצעדים ממשיים לקידום התלמיד/ה

**חלק ב: נתונים מובנים (JSON)**

לאחר הטקסט המלא, השב בדיוק בפורמט JSON הבא (אחרי סימן ``` או בשורה נפרדת):

{
  "schemaVersion": "1.0",
  "summary": "סיכום כללי של 2-3 משפטים על התלמיד/ה",
  "strengths": {
    "academic": ["נקודת חוזק אקדמית 1", "נקודת חוזק אקדמית 2", ...],
    "behavioral": ["נקודת חוזק התנהגותית/חברתית 1", "נקודת חוזק התנהגותית/חברתית 2", ...]
  },
  "barriers": {
    "academic": ["אתגר אקדמי 1", "אתגר אקדמי 2", ...],
    "behavioral": ["אתגר התנהגותי/רגשי 1", "אתגר התנהגותי/רגשי 2", ...]
  },
  "recommendations": {
    "immediate": ["המלצה מיידית 1", "המלצה מיידית 2", ...],
    "longTerm": ["המלצה לטווח ארוך 1", "המלצה לטווח ארוך 2", ...]
  },
  "learningStyle": {
    "preferences": "תיאור מפורט של העדפות למידה וסגנון הוראה מתאים",
    "seatingArrangement": "המלצת סידור ישיבה (אופציונלי)",
    "teachingStyle": "סגנון הוראה מומלץ (אופציונלי)",
    "materials": "חומרי לימוד מומלצים (אופציונלי)"
  },
  "goals": {
    "trackingMetrics": ["מדד מעקב 1", "מדד מעקב 2", ...],
    "followUpDate": "תאריך מומלץ למעקב (אופציונלי, בפורמט YYYY-MM-DD)"
  }
}

כללי חשובים:
1. כל המערכים חייבים להכיל לפחות 2 פריטים (strengths, barriers, recommendations, trackingMetrics)
2. כל משפט/פריט חייב להיות ברור, קונקרטי, ובר-ביצוע
3. השתמש בשפה חיובית ומעודדת גם כאשר מדברים על אתגרים
4. ודא שהתגובה היא JSON תקני שניתן לפרסר
5. אל תשתמש בפורמט markdown - רק JSON טהור
6. השלם את כל השדות הנדרשים
